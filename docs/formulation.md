# Постановка задачи: оптимальные билды как дифференциальная игра

## 1. Система единиц

Dota 2 использует hammer unit движка Source:

    1 unit = 1.905 см = 0.01905 м   =>   1 м = 52.4934 unit

Отсюда сразу получаются физически осмысленные величины:

| Величина | В unit | В метрах |
|---|---|---|
| Скорость передвижения 300 | 300 u/s | 5.71 м/с |
| Дальность атаки ближнего боя | 150 | 2.86 м |
| Дальность атаки дальнего боя | 600 | 11.43 м |
| Blink Dagger | 1200 | 22.86 м |
| Meat Hook (макс.) | 1300 | 24.76 м |
| Collision size героя | 24 | 0.46 м |
| Арена, короткая сторона | 1574.8 | 30 м |
| Арена, длинная сторона | 4199.5 | 80 м |

**Замечание об арене.** 30 × 80 м — это огромная площадка: ~1/4 площади карты Dota.
Для сравнения, Blink Dagger покрывает 76 % короткой стороны. Реальный дуэль
обычно разрешается внутри дистанции 600–1200 unit (11–23 м), поэтому
бо́льшая часть арены работает как «поле отступления», а не как поле боя.
Это подтверждается результатами (см. `results/`): оптимальная игра
происходит в подобласти, прижатой к одной из сторон.

Перемещение за один тик: `v·Δt`. При v = 300 u/s это 90 u = 1.714 м.
При замедлении до минимума (100 u/s) — 30 u = 0.57 м.
При haste (522 u/s) — 156.6 u = 2.98 м.

## 2. Непрерывная модель

Два агента `i ∈ {1,2}` (1 = Pudge, 2 = Invoker). Состояние в момент `t`:

```
x(t) = ( p₁, p₂,        позиции в арене A ⊂ R²          (unit)
         α₁, α₂,        углы поворота                    (rad)
         h₁, h₂,        здоровье                          (HP)
         m₁, m₂,        мана                              (mana)
         τ,             вектор кулдаунов способностей и предметов (с)
         β )            вектор активных бафов/дебафов с их остатками (с)
```

Управление каждого агента — пара

```
u(t) = ( ω, a ) ∈ S¹ × Act(x)
```

где `ω` — направление движения (непрерывное), `a` — боевое действие
(атака, каст способности, применение предмета, переключение toggl'а, ничего).

Динамика:

```
ṗᵢ    = vᵢ(x) · e(ωᵢ) · κᵢ(x)          vᵢ — текущая скорость бега (unit/s)
                                        κᵢ ∈ {0,1} — «может двигаться»
α̇ᵢ    = sat(ωᵢ_turn, turn_rateᵢ)        поворот ограничен turn rate
ḣᵢ    = −Dᵢ(x, u, v) + Rᵢ(x)            урон и регенерация
ṁᵢ    = −Cᵢ(x, u, v) + regenᵢ(x)
τ̇     = −1                              кулдауны тикают
β̇     = −1                              длительности тикают
```

`Dᵢ` — суммарный входящий урон в секунду; он **разрывен по состоянию и управлению**:
он включает дискретные события (попадание хука, каст, прок), а не только
непрерывный DPS. Формально это **гибридная система**: непрерывное движение
плюс дискретные переходы.

Терминальные условия:

```
h₁ ≤ 0                → победа игрока 2          (Pudge мёртв)
h₂ ≤ 0                → победа игрока 1          (Invoker мёртв)
pᵢ ∉ A                → поражение игрока i       (вышел за арену)
t → ∞                 → ничья, разрешается по доле оставшегося HP
```

Целевой функционал — вероятность победы игрока 1:

```
J(u, v) = P( Pudge убивает Invoker раньше, чем наоборот )
```

Игра **антагонистическая** (zero-sum), с **одновременными ходами**,
без дисконтирования. Это классическая **дифференциальная игра преследования
с терминальным множеством** (reach-avoid game); её решение в непрерывном
времени — вязкостное решение уравнения Гамильтона–Якоби–Айзекса (HJI):

```
0 = H(x, ∇V)  в  R \ T,     V|_T = терминальный выигрыш
```

где гамильтониан `H(x,p) = min_u max_v ⟨ p, f(x,u,v) ⟩` (порядок min/max
не важен при наличии седловой точки; при её отсутствии — это игра с
одновременным выбором, и решение задаётся **матричной игрой** в каждой точке,
а не чистым min-max).

Аналитического решения у HJI здесь нет: `f` разрывна, зависит от дискретных
кулдаунов и от табличных данных способностей. Поэтому решаем численно.

## 3. Дискретизация: игра Шепли

Сетка: `Δt = 0.3 с`, `Δx = 1 м`. Позиции героев живут на целочисленной решётке.
Ключевой приём: **множество достижимых точек за один тик — это пересечение
решётки с диском радиуса `rᵢ = vᵢ·Δt` вокруг текущей позиции.** Ошибка
округления не превосходит 0.5 м по построению и не смещена по направлению
(в отличие от «8 направлений», где возникает систематическая ошибка).
Число достижимых точек меняется от 1 (полностью замедлен) до ~29 (haste).

После дискретизации непрерывная игра превращается в **стохастическую игру
с одновременными ходами** (Shapley's stochastic game). Уравнение Беллмана:

```
V(s) = Val_{u∈U(s), v∈V(s)} [ γ · V( f(s,u,v) ) ]
```

где `Val[·]` — цена матричной игры (смешанное расширение), а
`f(s,u,v)` — детерминированный переход, реализуемый движком.

Терминальные состояния: `V = 1` (Invoker мёртв), `V = 0` (Pudge мёртв).
Дисконт `γ` вводится малым (`γ = 1 − 1e-4`) как регуляризация: он
гарантирует единственность решения и сходимость итераций по стоимости,
не меняя результата на горизонтах ≪ 1/(1−γ) тиков.

**Про ничьи.** При бесконечной игре `Val` может сойтись к промежуточному
значению — это и есть вероятность ничьей. Её разрешение (по доле HP)
закладывается в терминальную оценку.

### 3.1. Размер пространства состояний

| Компонента | Размер |
|---|---|
| Позиции (полное произведение, 31×81 на героя) | 6.3·10⁶ |
| HP (Pudge ~4000 → шаг 50; Invoker ~2000 → шаг 50) | 80 × 40 = 3.2·10³ |
| Мана | 30 × 30 = 9·10² |
| Кулдауны (~10 способностей/предметов, до 600 тиков) | 10⁵ … 10¹⁰ |

Полное произведение: **~10¹⁵–10¹⁸ состояний**. Точное ДП невозможно ни при
какой реализации. Это не инженерное ограничение, а принципиальное: задача
принадлежит классу, где прямое табулирование не масштабируется.

Поэтому применяется **трёхуровневая декомпозиция**, описанная в §4.

## 4. Декомпозиция

### 4.1. Уровень A — билды (внешняя комбинаторная игра)

Инвентарь — 6 слотов. Если считать только ~40 предметов, релевантных
дуэли 1-на-1, число мультимножеств:

```
C(45, 6) = 8 145 060
```

Но подавляющее большинство наборов **доминируемы**: предмет, дающий строго
меньше полезности по всем осям, чем другой, никогда не войдёт в оптимум.
Фактически значимы ~10 «осей полезности»:

```
EHP_physical, EHP_magical, burst_damage, sustained_dps,
mobility_range, lockdown_duration, kite_ability,
dispel_ability, sustain_hps, initiation_reliability
```

После отбрасывания доминируемых наборов остаётся **Pareto-фронт** размером
порядка 10². Именно на нём ищется равновесие.

**Ключевой концептуальный момент.** При неограниченном золоте «оптимальный
билд» в вакууме не существует: Dota устроена по принципу камень-ножницы-бумага
(BKB против магии, Blink против AoE, Ghost Scepter против физики, Linken's
против таргетных кастов). Если бы существовал один доминирующий набор,
мета была бы вырождена. Формально правильный вопрос — это **равновесие Нэша
мета-игры билдов**:

```
Игрок 1 выбирает B₁ ∈ 𝓑₁, игрок 2 выбирает B₂ ∈ 𝓑₂
Платёж: M[B₁][B₂] = V(дуэль на билдах B₁, B₂)
```

где `V` — цена внутренней тактической игры из §3. Решение — смешанное
равновесие матричной игры `M`, вычисляемое итеративно (fictitious play /
лемке-хаусон). Дополнительно считаем **равновесие Штакельберга** —
если один игрок выбирает билд вторым, зная билд противника (это реальная
ситуация в Dota: пик и последняя закупка).

### 4.2. Уровень B — тактика (внутренняя игра)

Полное пространство состояний неприводимо, но в пустом изотропном
прямоугольнике динамика зависит от геометрии только через две величины:

* `d = |p₂ − p₁|` — дистанция между героями (входит во все проверки дальности);
* `rᵢ` — свободное место для отступления от `pᵢ` в направлении от противника
  (входит в проверку «выход за арену = поражение»).

Обоснование: арена пустая и изотропная, препятствий нет, все способности
зависят от расстояния, а не от абсолютных координат. Значит, игра инвариантна
относительно переносов вдали от стен. У стен инвариантность нарушается —
это обрабатывается отдельно как **пограничный слой** (§4.3).

Редуцированное состояние:

```
σ = ( d, r₁, r₂, h₁, h₂, m₁, m₂, τ̂, β )
```

|d| ≈ 86 (0…85.4 м, диагональ арены), |rᵢ| ≈ 81.
«Ядро» (без стен): 86 значений `d`.

Дальнейшее сокращение — по **точности HP** и по **числу кулдаунов**:

* HP квантуется так, чтобы ошибка квантования была меньше половины
  наименьшего значимого источника урона (иначе появляются ложные «выживания»);
* из вектора кулдаунов `τ` оставляются только те, что реально меняют решение.
  Кулдауны длиннее горизонта дуэли (Refresher, 180 с) заменяются флагом
  «доступен один раз», а быстрые (Rot, 0 с) вообще убираются из состояния.

### 4.3. Пограничный слой

Вблизи стен условие «вышел — проиграл» меняет игру качественно: отступление
становится невозможным, и герой без мобильности теряет опцию.
Внутри полосы шириной ~`v·Δt_max` у стены решаем игру точно на полной
2-D решётке (там состояний мало, потому что полоса тонкая), а не в
редуцированном представлении.

### 4.4. Иерархическое уточнение

1. Грубая сетка (HP шаг 200, мана шаг 100, 8 направлений) → приближённая
   функция ценности и **область оптимальных траекторий**.
2. Локальное уточнение только тех состояний, что лежат на оптимальных
   траекториях и в их окрестности.
3. Валидация: прогон найденных политик в полном высокоточном движке
   (шаг 1/30 с, непрерывные позиции) и проверка, что цена не улучшается
   при отклонении.

Такой цикл «решил грубо → уточнил где важно → проверил симулятором» даёт
тот же ответ, что точное ДП, но на много порядков дешевле.

## 5. Алгоритм решения

```
АЛГОРИТМ Duel-Solve(hero1, hero2, level, K)

 1. Собрать все билды-кандидаты 𝓑₁, 𝓑₂ (6 слотов из пула релевантных предметов)
 2. Отфильтровать доминируемые → Pareto-фронты P₁, P₂
 3. Пока равновесие не сошлось:
      a. Для каждой пары (B₁, B₂) ∈ P₁ × P₂:
           V(B₁,B₂) ← Tactical-Solve(B₁, B₂)
      b. Обновить смешанные стратегии (fictitious play)
 4. Вернуть равновесие (p*, q*) и цену игры

АЛГОРИТМ Tactical-Solve(B₁, B₂)

 1. Построить редуцированное пространство состояний Σ (§4.2)
 2. Инициализировать V ← 0.5 на нерешающих, 1/0 на терминальных
 3. Итерации по стоимости (Гаусс–Зейдель, приоритетная очередь):
      V(s) ← Val_{u,v}[ γ·V(f(s,u,v)) ]
      где Val — цена матричной игры (сначала проверка седловой точки,
      LP только если седловой точки нет)
 4. Извлечь оптимальные политики π₁(s), π₂(s)
 5. Вернуть V(стартовое состояние)
```

## 6. Что именно даёт решение

Для пары Pudge/Invoker 15 уровня ответ имеет вид:

* **цена игры** `V*` — вероятность победы Pudge при оптимальной игре обоих;
* **равновесные билды** — смешанные стратегии на Pareto-фронте, с указанием,
  какие предметы входят в поддержку равновесия;
* **оптимальная дистанция боя** — при каком `d` Pudge обязан инициировать,
  а при каком Invoker обязан отступать;
* **структура оптимальной игры** — например: «Pudge обязан держать дистанцию
  ≤ X м до готовности хука; при готовности — инициировать немедленно,
  потому что промедление даёт Invoker шанс на Cold Snap».
* **критические пороги** — например, сколько EHP нужно Pudge, чтобы пережить
  полный комбо-цикл Invoker, и какие предметы это обеспечивают минимальной
  ценой (при неограниченном золоте критерий — не цена, а **число слотов**).
